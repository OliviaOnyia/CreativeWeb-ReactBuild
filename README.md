## The journey 

I had learnt HTML and CSS in a one of class in highschool but never
got the chance to dive back into it.
I tried learing python on and off since university but it never stuck.

Then in 2024, while doing my Masters in Game Audio and Music, I was 
running into audio coding problems in Unity, that I needed to fix myself.
So I dug around in the C# code, lost but intrigued and was able to 
write 3 customized audio trigger codes and music trigger zone codes.

This then launched me back into wanting to learn and do more with code,
I just didn't know where to start. 
> So I thought, "Why not learn WebDev?"

I searched for online courses and decided to settle on Codeacdemy, 
but I found that it wasn't as helpful or encouraging to truly learn. 
But I stuck it out for a few months and then it dwindled. 
So I cancelled the subscription and just moved away from coding for a bit.

It was a good foundation to learn HTML, CSS and a bit of JavaScript, as that was as far as I got.

> Insert Creative Process Digital Course: Software Development
Then after not really being happy with my website being on wix,
I needed to learn how to build a website..again.
Which was perfect timing for me, as I saw the Creative Process Digital
was about to start a Software Development course, which was 
just what I was looking for.

So everything that you see is an accumlation of an 8-week course
on this programme
